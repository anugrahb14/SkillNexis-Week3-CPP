# Skill Nexis - C++ Week 3

This repository contains the C++ OOP assignments and mini project completed for Week 3 of the Skill Nexis C++ Programming Internship.

## Week 3 Assignments

### 1. Employee Class
A program using an `Employee` class with a salary calculation method.

### 2. Constructor Overloading
A program demonstrating multiple constructors with different parameter lists.

### 3. Shape Inheritance
A program demonstrating inheritance using:
- `Shape`
- `Rectangle`
- `Circle`

### 4. Abstract Class with Virtual Function
A program demonstrating an abstract `Shape` class with a pure virtual function and derived class implementations.

## Mini Project

### Library Management System

An OOP-based console application that demonstrates:

- Book class
- Member class
- Constructors
- Encapsulation
- Book issue and return
- Search by title
- Search by author
- Interactive menu
- Book status management

## OOP Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstract Classes
- Virtual Functions

## Project Files

- `employee.cpp` — Employee class and salary calculation
- `constructor_overloading.cpp` — Constructor overloading
- `shape_inheritance.cpp` — Shape inheritance
- `abstract_shape.cpp` — Abstract class and virtual function
- `library_management.cpp` — Library Management System
